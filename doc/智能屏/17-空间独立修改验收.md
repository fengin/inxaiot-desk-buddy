# 智能屏空间独立修改验收

日期：2026-10-03。工程：`inxaiot-desk-buddy`（桌面运维工作台程序），运行环境：Windows。

## 1. 业务规则

运维人员可以在工作台修改智能屏所属空间。修改空间与调整布点分别处理；屏已有坐标、空间已有图片、样式、设备类别或设备别名，均不阻止提交。

- 登记更新和人工合并采用同一规则。
- 目标空间必须有效且属于当前业务项目；保留资料并发修改和操作占用检查。
- 数据库表 `smart_terminal_screen` 的字段 `building_id` 保存新空间，布点字段 `point_x`、`point_y` 保留原值。
- 空间图片、样式、设备类别、设备关联和别名保持原值，不由工作台清除或迁移。
- 用户自行在项目平台调整布点。工作台继续展示原、新空间和已有的空间修改确认，不增加布点确认流程。

## 2. 实现位置

以下路径位于工作台工程：

| 文件 | 调整 |
| --- | --- |
| Rust 文件 `src-tauri/src/infrastructure/smart_screen/registration.rs` | 登记预览不再查询和拦截布点、空间配置 |

| Rust 文件 `src-tauri/src/infrastructure/smart_screen/merge.rs` | 人工合并选择另一空间时，也允许保留原布点后提交 |
| TypeScript 文件 `src/dev-fixtures/screenFixtureAdapter.ts` | 演示流程的确认和日志不再要求确认布点影响 |

需求、界面流程、原型说明、技术方案和开发计划已同步该规则。原阶段记录保留当时的测试事实，当前空间修改规则以本文和需求、技术方案正文为准。
