# 操作表单字体统一验收

> 日期：2026-10-08。
> 范围：智能屏与一体机的操作参数、文件选择、配置编辑及发布参数表单。
> 状态：字体、布局补验、相关回归及 Windows 普通构建通过。

## 1 当前文字层级

实施人员填写和核对字段时，标签与输入内容采用相同字号和常规字重；说明、文件信息和校验反馈小一档。具体规则已写入[界面规范第 8.2 节](01-桌面工作台界面设计规范.md#82-表单)。

| 内容 | 小 / 标准 / 大字号 | 字重 |
| --- | --- | --- |
| 字段标签、输入值、占位文字、下拉已选值与选项、单选/复选文字、文件选择按钮 | 12 / 13 / 14px | 400 |
| 说明、文件大小、应用版本和架构、校验反馈 | 11 / 12 / 13px | 400 |
| 分区标题、设备名称与统计数字 | 沿用原有层级 | 保留必要强调 |

“本地 APK 文件”和镜像服务名不再使用粗体标题。模板编辑区保留等宽字体，输入文字与其他字段同一字号。紧凑文件控件只调整文字，不增加控件高度；表格中的辅助小按钮不随之放大。

发布参数标签列改为随字号变化的 8em，与一体机脚本字段对齐。“账号”“密码”等完整词不拆成孤字换行。1024×640 的大字号舒适模式下，智能屏长安装参数可在自身区域滚动，“安装检查”按钮固定在滚动区外，设备列表仍独立滚动。
