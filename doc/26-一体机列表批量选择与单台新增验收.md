# 一体机列表批量选择与单台新增验收

日期：2026-10-08。适用范围：Windows 运维工作台的一体机列表与部署升级页面。

## 使用方式

实施人员可以在一体机列表勾选目标，再进入部署升级；也可以填写单台资料加入工作台，省去准备 CSV 文件的步骤。

1. 名称列左侧提供选择框。表头选择当前页可操作的一体机，部分选中显示半选；翻页和筛选保留选择，切换项目清空。信息冲突或 MAC 无效的记录不能勾选。
2. 底部分页统计右侧提供“批量操作”。点击后，部署升级页面仅勾选带入的有效目标，仍默认单服升级。该操作不启动检查或部署；目标已删除或出现冲突时说明未带入数量，不自动补选其他设备。
3. “导入清单”右侧提供“新增一体机”。名称、IP、MAC 必填，位置和备注可选。新记录按原导入规则保存为工作台资产，不直接修改设备或平台业务资料。
4. 已存在于工作台的 MAC 不重复新增；平台已有且名称、IP 一致时，需要确认接管。资料冲突时停止保存。已有未处理 CSV 预览时先处理原预览，新增不覆盖它。

新增表单采用两列紧凑布局。取消及项目切换只清理本次新增建立的预览；已开始保存的请求仍归原项目，返回后不能关闭或覆盖新项目表单。

## 实现位置

以下均位于已有工程 `inxaiot-desk-buddy`，运行在运维人员电脑上：

| 文件或目录 | 职责 |
| --- | --- |
| Vue 文件 `src/features/aio/nodes/AioNodeListView.vue` | 列表选择、批量跳转和新增按钮 |
| Vue 文件 `src/features/aio/nodes/AioNodeCreateDialog.vue` | 单台表单、必填提示、平台接管确认及请求隔离 |
| Vue 文件 `src/features/aio/operations/AioOperationsView.vue` | 接收项目与 MAC 范围、重新匹配有效目标，仅预选 |
| TypeScript 文件 `src/shared/api/aioAdapter.ts`、`aioNodes.ts`、`realAioAdapter.ts` | 前端新增预览调用与正式命令封装 |
| Rust 文件 `src-tauri/src/interface/commands/aio_assets.rs` | 桌面命令 `preview_aio_node_create`，检查项目访问条件 |
| Rust 文件 `src-tauri/src/infrastructure/aio_assets_service.rs` | 单台校验与分类，继续使用原预览和应用方法 |
| Rust 文件 `src-tauri/src/domain/aio/inventory.rs` | CSV 和单台新增共用的字段校验 |

新增不增加数据表。预览继续存在本机 SQLite；最终一体机资产、审计和操作摘要仍通过原有工作台库事务保存，原导入流程的权限、版本和冲突检查继续生效。

检查覆盖：

- 单台表单：三项必填、新增成功、重复 MAC、平台接管确认/取消、已有 CSV 预览保留、旧请求迟到及跨项目并行保存。
- 批量选择：当前页全选/半选、跨页与筛选保留、冲突禁选、项目切换清空、MAC 格式统一、缺失目标提示、不补选其他设备，以及原详情页单台跳转。
- 原有一体机流程：服务检查、状态管理、部署页交互、CSV 黄金样例、300 台解析分类及本机预览唯一性。
- 界面：1024×640、1280×800 下的列表、部署页预选、新增弹层及必填提示，截图和结果位于 `.review-tools/aio-list-20261008/`。

验证使用本机模拟数据和临时 SQLite，未连接实际一体机，也未写真实项目数据库。桌面程序沿用普通应用标识；启动不会自动部署。
