## 2. 数据边界

- `local_task/local_task_target/local_task_step` 保存本机实时任务、节点、步骤和进度。
- 任务事件和远端 stdout/stderr 写入本机 JSONL，不写工作台 MySQL。
- 项目侧仍只保存操作摘要和节点最终结果，本阶段不扩展项目侧过程表。
- 本机绝对路径、临时文件、完整哈希和上传进度不得进入项目侧记录。

## 4. 正式实现

### 4.1 远程与文件

- `application/ports` 定义远程会话、命令、文件传输和文件处理端口。
- `infrastructure/remote` 使用 Russh/Russh-SFTP 实现密码、内存私钥、主机密钥策略、命令输出、取消和分层超时。
- 上传使用 `.part-{operationId}`，完成前核对远端大小和可选 SHA-256；下载使用本机同操作 ID 临时文件。
- `LocalFileProcessor` 负责选择根目录边界、流式哈希、复制/复核分阶段进度和任务目录精确清理。
- `HostKeyRepository` 和 `RecentArtifactRepository` 只写本地 SQLite。

### 4.2 任务与日志

- `TaskRepository` 原子保存任务、目标和步骤，所有可见事件通过同一任务 sequence 单调递增。
- `TaskQueue` 是有界优先级队列；排队任务可在派发前取消，运行任务由 `JobSupervisor` 管理取消令牌和 JoinHandle。
- `execute_in_batches` 保证一波完成后再进入下一波，并用 Semaphore 限制节点并发。
- `TaskEventPipeline` 依次完成 sequence 预留、敏感信息脱敏、JSONL 刷盘和有界广播。
- 日志支持级别、关键词、最新页和向前分页；读取过程使用两遍流式扫描，不一次加载完整日志。
- 应用启动把上次未完成的执行任务标记为中断/待对账；正常退出取消任务并关闭项目运行时和 SQLite。

### 4.3 桌面接口

- Tauri 管理唯一 `AppState`，注册任务列表、日志分页和运行中任务取消命令。
- `task-event` 从 Rust 有界总线转发到 WebView。
- 活动面板在 Tauri 中读取真实本地任务和日志；浏览器 Demo 继续使用 Fixture Adapter。
- 日志面板支持级别/关键词过滤、加载更早记录、自动跟随、暂停跟随和“回到最新”。

## 6. 阶段边界

阶段 4 提供可复用的执行基础设施，不代表一体机三类部署业务已经完成。Release manifest、模板渲染、资产导入、平台注册和三类部署 Handler 在后续阶段组合这些端口；不得从前端暴露任意命令、任意本地文件或原始 SQL。
