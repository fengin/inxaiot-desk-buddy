# INX 实施工作台界面 Demo 验收说明

| 属性 | 内容 |
| --- | --- |
| Demo版本 | `0.1.0-demo.5` |
| 技术栈 | Rust + Tauri 2 + Vue 3 + TypeScript + Naive UI + UnoCSS |
| 数据模式 | Demo验收时为前端固定Mock；当前浏览器保留Mock、Tauri使用真实后端 |
| 更新日期 | 2026-08-27 |

## 1. 验收目的

本阶段只验证产品信息架构、界面风格、页面排版和关键交互是否支持实际业务目标，不连接项目数据库、平台服务、SSH、SFTP或一体机Agent。

验收反馈可能引起产品设计、界面规范和技术方案调整，当前Demo代码不作为业务实现完成的证据。

## 2. 运行方式

### 浏览器快速预览

```powershell
pnpm install
pnpm dev
```

访问：`http://127.0.0.1:1420/`

### Tauri桌面运行

```powershell
pnpm tauri dev
```

### 已验证的Release程序

```text
src-tauri/target/release/inxaiot-desk-buddy.exe
```

## 3. 已实现界面范围

### 全局桌面框架

- 自定义标题栏和窗口控制。
- 顶部项目选择、新增、编辑和独立登录会话Demo。
- 左侧“一体机管理—二级功能”分级导航。
- 智能屏管理、网关管理一级“规划中”菜单。
- 底部项目状态栏。
- 从底部向上展开的任务/日志面板，Tab直接位于面板标题栏。
- 滚动区域固定保留细滚动条槽位，滑块仅在悬停时显示，避免内容宽度闪动。
- 浅色、深色、三档字号、紧凑/舒适密度、减少动画、每页条数和工作台数据目录设置。

### 一体机列表

- 总数、在线、离线、待实施和冲突摘要，仅使用独立状态色图标，状态文字保持统一颜色。
- 搜索和状态筛选。
- 已管理、待实施、平台已存在、冲突和不可达示例。
- 右侧一体机详情检查器。
- 镜像和版本聚合弹窗。
- CSV选择、校验预览和最终资产应用Demo。

### 发布参数

- 平台、MQTT和SSH共享参数。
- `.env`和`docker-compose.yml`模板页签。
- 编辑、取消和保存版本交互。
- 配置校验、修改时间和凭据可见状态与页面标题同行显示。

### 部署升级

- 首次部署、整包升级和单服升级模式。
- “选择—检查—部署/升级—结果”四阶段流程。
- 节点范围、批次大小、并发数和本地发布文件。
- 集中检查结果和渲染预览。
- 模拟上传、执行、服务检查、日志和最终结果；总体进度与执行状态合并在同一标题区。
- 项目侧操作摘要和节点最终结果历史，可由列表进入详情。

## 4. 重点验收问题

1. 顶部项目入口、左侧业务导航和底部状态是否职责清楚。
2. 一体机列表能否快速回答数量、在线状态、部署状态和异常对象。
3. “平台已存在但无工作台历史”的接管场景是否容易理解。
4. 导入清单只保留本地预览、确认后写最终资产的表达是否清楚。
5. 发布参数和模板放在同一页是否便于维护。
6. 部署升级四阶段是否比原流程更直接。
7. 检查阶段是否能一次看清所有阻断项。
8. 底部任务日志面板是否适合持续查看长任务。
9. 操作历史只保留摘要和节点最终结果是否满足追踪需要。
10. 当前字体、密度、颜色、按钮层级和信息量是否适合长期桌面使用。

## 6. Demo验收时明确未实现（历史）

- 项目选择器、登录弹窗和各业务页面尚未全部切换到真实项目/平台数据。
- CSV文件实际读取。
- 发布参数真实保存和版本冲突。
- Release包、镜像和模板真实校验。
- 一体机部署业务 Handler 尚未组合 SSH/SFTP、Agent、租约和项目最终结果。
- 首次主机密钥确认界面尚未接入业务页面；通用 TOFU 仓储和变化阻断后端已完成。
- Shell Agent 的部署/升级和 Docker/Compose 写操作尚未由正式业务流程触发；阶段 4 只验证现有 Agent 的只读兼容命令。

以上内容记录2026-08-27界面Demo验收时的实现边界，不代表当前阶段7状态。

## 7. 阶段 4 接入更新

2026-08-27 已完成以下 Demo 后续实现：

- Tauri 启动真实 AppState、本地 SQLite Migration、应用日志和中断任务恢复。
- 底部活动面板在 Tauri 模式读取真实本地任务、目标聚合和 JSONL 日志；浏览器模式继续使用 Demo Fixture。

- 通用 SSH/SFTP、文件处理、任务队列、进度和日志后端通过专项及真实环境验收，详见 `09-阶段4通用执行基础设施验收记录.md`。
