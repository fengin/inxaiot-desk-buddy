# 登录后自动刷新验收

日期：2026-10-08。适用于当前项目尚未登录时进入智能屏列表或操作页面，随后通过项目登录恢复平台访问的场景。

## 当前行为

- 当前项目登录成功后自动读取平台，更新屏记录、空间、统计和可用条件；成功后消除旧认证提示，无需手动刷新。
- 保留当前筛选、有效选中项、分页和操作页面；不触发设备检查、安装或平台写入。
- 登录失败或读取失败时保留对应原因，不提前宣称平台可用。
- 平台可读但共享数据库不可用时，仍刷新平台数据；共享写操作继续使用原权限条件。
- 退出或会话失效时重新读取可用范围。正常会话定期校验没有状态变化时，不重复刷平台。

## 原因与代码位置

原页面只监听项目编号变化。同一项目登录后编号不变，因此没有重新读取；任务进度通知又可能只更新本机结果，不能代替平台刷新。

工作台已有 Vue 文件 `src/features/smart-screen/ScreenWorkspace.vue` 增加平台访问条件监听；TypeScript 文件 `src/stores/smartScreens.ts` 负责显式平台刷新及通知合并；接口文件 `src/shared/api/screenAdapter.ts` 和正式适配器文件 `src/shared/api/realScreenAdapter.ts` 传递明确刷新参数。后端登录、权限和数据存储规则不变。

## 验证范围

验证使用本机模拟数据，不登录真实平台、不连接实际屏：

- 未登录进入列表和操作页面，登录后提示消除、平台数据恢复，页面选择不丢失。
- 登录失败、共享连接失败、退出登录及正常会话校验的准确处理。
- 登录前请求迟到不覆盖新结果；切项目后旧读取、旧失败不影响新项目。
- 多条任务通知在平台读取期间合并，结束后只补一次本机读取；关闭页面后停止订阅。
- 强制平台读取消费旧本机刷新标记，普通任务刷新继续保留原本机读取方式。

当前程序路径和文件校验值见[开发测试遗留与接续计划](20-智能屏开发测试遗留与接续计划.md#22-当前交付文件)。

验证结果：登录与工作区交互、正式适配器、状态管理、原有智能屏及注册流程共 6 个测试文件、72 项通过；受影响页面类型检查、代码检查和普通 Windows 桌面构建通过。本次未恢复实机测试。
