# 智能屏反馈调整验收

日期：2026-10-03。适用工程：`inxaiot-desk-buddy`（桌面运维工作台程序）。当前验收环境为 Windows，测试服务器为 192.168.3.142，测试屏为 4 寸 192.168.3.114 和 10 寸 192.168.3.73。

空间修改的当前规则见[空间独立修改验收](17-空间独立修改验收.md)，接手操作的当前流程见[当前页面接手操作验收](18-当前页面接手操作验收.md)。本文保留原测试记录，表示当时的验证范围，不作为当前空间修改限制。

## 1. 本次记录的行为

| 事项 | 实现及操作方式 |
| --- | --- |
| 另一电脑释放占用 | 在智能屏运维历史的“平台结果记录”中选原操作，查看占用，再次确认后释放。保存操作人和来源电脑；占用归属变化时要求重新确认。原任务不能继续取锁或写入。人员线下协调，软件不核查协调过程；已发给设备的命令不能视为已撤销 |
| 混合批次平台故障 | 包含已注册屏的设备写操作，在预检或开始时平台连接、登录或共享记录不可用，整批不执行；提示单独选择本机未注册屏。执行中故障保留已有成功事实。只读检查保留原有离线能力 |
| 平台删除屏 | 完整刷新后，确认记录本身已逻辑或物理删除，清理本机屏、关联、草稿、列表和检查缓存；保留任务、日志和未确认写入依据。移到其他业务项目不算删除，查询失败不清理 |
| 空间变更 | 检查屏布点、原空间和目标空间的图片、设备类别、屏样式、设备关联、别名及布局布点。有影响时列明原因并引导平台处理；空空间可以修改。实际保存再次检查，禁止仅凭旧预览写入 |
| 未知与检查信息 | 未检查不显示成失败、0MB 或零偏差；平台未知不计作离线；Ping 不覆盖 ADB 检查。详情补型号、固件、应用状态、MAC 来源、时间、时区和自动校时设置；校时检查页显示时间依据 |
| 筛选 | 保留现有控件及规则。版本筛选按已注册屏的平台登记值、未注册屏的实测值；前端使用完整快照筛选、统计和分页 |
| 重试关联 | 安装、设备维护及只读检查的重试保存原操作编号；后端核对项目、动作、原任务状态、结果保护和目标范围。原操作已有共享记录时，使用已有数据库字段保存关联。登记重试仍重新预览，暂不增加关联 |
| 诊断与共享摘要 | 诊断保留设备与应用检查、最近 200 行指定系统日志，单台上限 512KB；不采小新私有日志和配置。共享安装结果补文件名、版本和 SHA-256 校验值，完整文件和日志仍留本机 |
| 发布工具 | 内部发布及多平台压缩包流程接入 ADB、aapt、apksigner、Java 21、许可证和校验清单；工具不能运行则发布失败。内部产物清单升级为 v4，交付完整目录 |
| macOS | 是确定支持目标。代码已区分工具名称、应用包内路径及 Ping 参数；Intel、Apple Silicon 保留构建流程，真实 Mac 验收尚未完成 |

数据库字段 `smart_terminal_screen.version` 继续保留 H5 样式含义，小新版本仍使用 `app_version`。本次未变更项目平台业务表结构。

## 2. 技术位置

所有以下路径均相对工作台工程，程序在运维电脑运行。

- Rust 文件 `src-tauri/src/infrastructure/smart_screen/lock_release.rs`、`leases.rs`：二次确认释放、审计、旧任务阻断。注册、合并、版本和状态操作在执行前建立共享记录，供其他电脑查看。
- Rust 文件 `platform_write.rs`、`registration.rs`：空间关联检查；参考项目平台保存逻辑，使用数据库表 `t_project_building` 和 `op_device_service_area`，不修改它们。
- Rust 文件 `platform.rs`、`assets_service.rs` 和 `infrastructure/local_sqlite/screen_repository.rs`：确认删除及本机事务清理。
- Vue 页面 `src/features/smart-screen/ScreenDetail.vue`、`ScreenTimeCheck.vue`、`ScreenSharedHistory.vue`：详情、校时依据及释放确认；TypeScript 文件 `src/shared/api/realScreenAdapter.ts`：区分平台资料和本机实测。
- 构建脚本 `scripts/package-screen-tools.mjs`：跨系统工具打包及验证；PowerShell 脚本 `release-internal.ps1`、`verify-internal-release.ps1`：内部完整目录发布和校验；流水线文件 `.github/workflows/portable-release.yml`：多平台工具准备与压缩包。
