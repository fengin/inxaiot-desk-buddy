# 0.2.13 发布回归记录

验证日期：2026-10-21。工程为 `inxaiot-desk-buddy`（实施工作台程序），发布标签为 `v0.2.13`。

## 1. 业务范围

本版本面向项目实施、运维人员，包含智能屏注册提示、资料草稿展示、空 MAC 补齐、版本同步提示、语音启动配置兼容、列表交互性能、本地时区显示以及操作说明和布局调整。一体机列表刷新及共享观测时间同步回归。完整变更见[版本记录](../CHANGELOG.md)。

应用版本与普通登记资料分别处理：已注册屏安装成功并核实后自动回写平台 `app_version`（小新版本数据库字段）；先安装后注册、同版本跳过或平台版本缺失时，可以通过列表“版本待同步”进入重新读取和确认同步。普通“注册/更新到平台”不直接上传缓存版本。平台已有 H5 样式字段 `version` 不受影响。

版本提示只采用当前已确认 IP 的有效观测。旧地址的历史观测在详情中保留供追溯，不当作当前屏的待同步值。点击提示先把目标传入同步面板，再开始一次读取，避免空目标的重复请求。

## 3. 静态检查边界

全仓 `cargo fmt --all -- --check` 和严格 Clippy 命令未通过，不能把本次结果描述为完整 `quality-gate.ps1` 全绿：

- 格式检查在当前源码出现 80 个文件、478 处差异；提交前基线也有 73 个文件、258 处差异。66 个完全未修改文件两次均有差异；本轮也存在增量格式差异，没有将其全部归于历史问题。
- `cargo clippy --offline --all-targets --all-features -- -D warnings` 报告 43 个主诊断，涉及参数数量、可合并条件、借用和集合写法、测试模块位置等。37 项位于未修改文件；其余 6 项涉及的原语句在旧提交中已经存在，其中一项随本轮校验方法提取而移动。此结论基于源码位置和字节比较，没有冒称旧提交已执行 Clippy。
- 源码审查未在这些诊断中发现新的运行逻辑故障。本次保留功能范围，没有为消除告警重排或改写无关存量模块；正式编译与功能测试结果分别按上表判断。
