## 配套应用与操作边界

设备 OWNER 是 Android 的设备所有者权限。已属于小新时只读显示；设备尚无所有者时，人员可将设置权限加入本次任务；其他应用持有或状态未知时，主屏、锁定等依赖动作不可继续。勾选只表示意图，后台设置并独立回读成功后才执行依赖动作；工作台不提供解除 OWNER。

锁定管理需要配套新版小新提供独立的读取、保存及应用能力。实施前先保留数据覆盖升级安装包，再重新读取设备能力，不能只更新工作台或按版本号认定可用。已保存关闭和原保存项缺失分别显示；缺键只形成默认开启的橙色待提交目标，检查确认前不写屏。混合值按保留、全开、全关选择；保存值和实际运行状态不一致时另行核验并使其一致，未知不能当作关闭。

单独修改锁定不重启小新；开启且主界面未就绪时，已确认任务可显式唤醒并启动小新。需要激活主屏而当前锁定开启或仍生效时，必须明确关闭锁定，允许同批先解锁再主屏。取消和异常恢复只读取事实，不重放设置权限、保存、应用、唤醒、启动或重启；已完成动作保留，不能宣称已撤销。

当前验证结论集中维护在[开发计划第 11.4 节](06-智能屏开发与验收计划.md#114-设备owner与应用锁定扩展)。自动回归、原生三屏接口验证、工作台正式三屏完整任务链分别记录，前两者不能替代完整实机验收或现场声学测试。
