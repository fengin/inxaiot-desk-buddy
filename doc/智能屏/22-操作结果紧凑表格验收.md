# 操作结果紧凑表格验收

> 日期：2026-10-07。
> 状态：本机界面、相关自动测试和 Windows 普通构建通过；实机测试仍暂停。

日志的当前交互规则见[结果状态对齐与日志统一验收](../24-结果状态对齐与日志统一验收.md)。下文保留当时的界面与验证记录。

实施人员执行智能屏操作后，在固定的结果概览下查看逐台结果。设备较多时，只滚动设备数据行；概览、进度、操作按钮、表头、分页和底部新操作按钮保持可见。

## 1 当前展示

- 每台屏只占一行，屏名称、IP 和状态分别成列。“修改小新配置”在同一行增加保存、重启、回读三列，不再重复生成每屏卡片。
- 结果说明、未保存字段及记录保存情况保留。长内容省略显示，悬停可看完整内容；状态列留出完整状态文字所需宽度。
- 表格不再使用额外增加 22px 的固定行高。常规行采用公共紧凑高度，有多行结果说明时按内容撑高。
- 表头与数据体共用列宽，数据体使用 4px 公共细滚动条，滑块移出隐藏且占位不变。
- 每页支持 20、50、100 台，默认 50 台。分页只影响展示，进度和重试、版本核对范围仍按完整任务计算。
- “本次日志”使用独立弹窗，保留“任务与日志面板”的当前任务定位。日志不再挤占主结果页的列表高度。
- 配置结果、普通操作结果和本机历史均使用上述布局。本机历史左侧任务目录继续独立滚动；项目共享历史保持原有查看方式。

取消后续执行、继续核实、重试失败目标、仅重启已保存配置、版本同步、状态差异和诊断导出仍沿用现有业务规则，不因分页或布局变化重新执行设备动作。
