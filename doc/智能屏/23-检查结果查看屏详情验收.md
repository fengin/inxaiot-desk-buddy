# 检查结果查看屏详情验收

验证日期：2026-10-08。范围为 Windows 工作台的界面与本机模拟数据，不连接实际屏或项目数据库。

## 使用规则

实施人员完成“检查屏在离线”“检查设备”或“获取/核对 MAC”后，可以在结果表末列点击“查看屏详情”，查看该屏保存在本机的检查信息与检查时间。本机历史中的这三类检查也提供相同按钮。

- 复用智能屏列表的详情抽屉；不跳离结果页面，不再次执行设备检查。
- 关闭详情后保留结果页码与滚动位置。从历史记录打开时，历史抽屉仍保留。
- 详情显示本机最新资料，不是较早任务的历史快照；MAC 采集时间与设备检查时间分别显示。
- 登记或合并后的旧记录编号可找到当前屏。已移除的屏只提示记录已移除，历史结果与日志保留；不按同 IP 或同名称打开其他屏。
- 结果表仍保持固定表头和分页，只有设备列表内容滚动。

## 在线检查业务状态

“检查屏在离线”结果表的在线状态以当次任务保存的实测为准：在线显示绿色，离线显示红色；程序异常、旧记录缺少有效实测或检查地址不一致显示未知，具体原因在实际结果中说明。等待或取消未检查的屏显示未检查，执行期间显示检查中。检查正常完成不等于设备在线，后来检查到的新状态不覆盖历史任务的结果。

程序模型文件 `src/shared/model/screen.ts` 补充已有检查数据的类型；结果组件读取本次任务的检查数据，模拟适配器同样保存每次检查的在线结果。后端检查、公共任务状态和平台写入规则未改动。相关 4 个测试文件合计 59 项通过；1024×640、1280×800 下的当前结果与本机历史共 4 个浏览器场景通过，证据位于 `.review-tools/ping-results-20261008/`。
