## 1. 资料回顾与阶段边界

本阶段只建立所有业务模块共用的本地基座：

- `AppState` 只持有 SQLite、SecretStore、项目运行时注册表、任务监督器和应用目录。
- 本地 SQLite 保存多项目入口、会话引用、偏好、实时任务、步骤、进度、导入预览和本机文件引用。
- 项目最终资产、共享配置、操作摘要、节点最终结果和跨实例锁不得进入本地库。
- 数据库密码和平台令牌只保存 SecretStore 引用，不保存明文。
- SQLite 使用 WAL、外键、busy timeout 和 SQLx `_sqlx_migrations`。
- 任务取消由 `CancellationToken` 管理；切换项目不依赖一个全局可变业务状态。

## 2. 已实现内容

### 2.1 本地目录

实现统一 `AppPaths`：

```text
app_data/
├─ local.db
├─ known_hosts
├─ logs/
├─ projects/
└─ runtime/agent/
```

项目和任务目录段禁止空值、`.`、`..`、斜杠和反斜杠，防止路径逃逸。

### 2.2 SQLite Migration

首个本地 Migration 创建：

- `local_project`
- `local_project_session`
- `local_preference`
- `local_task`
- `local_task_target`
- `local_task_step`
- `local_aio_import_session`
- `local_aio_import_item`
- `local_recent_artifact`
- `local_host_key`

阶段 4 追加第二个本地 Migration，为通用任务运行补充名称、优先级、批次、并发、payload 引用、错误摘要以及目标的当前/总进度和消息字段。SQLx `_sqlx_migrations` 实际成功数为 2；没有新增业务侧任务过程表。

没有创建 `aio_node`、`operation_record` 或 `resource_lease`，符合最终数据边界。

### 2.3 SecretStore

- 定义业务无关 `SecretStore` 端口。
- 实现 Windows Credential Manager 适配器。
- 实现确定性的内存适配器供单元测试使用。
- 本地项目和项目会话只保存 SecretStore 引用。

### 2.4 项目运行时与任务监督器

- `ProjectRuntimeRegistry` 按本地项目 ID 隔离和复用运行时。
- 同一项目重复打开返回同一 `Arc<ProjectRuntime>`。
- 不同项目互不复用运行时状态。
- `JobSupervisor` 拒绝重复任务 ID，持有取消令牌并在结束时移除。
- 应用关闭门禁验证项目运行时清空和 SQLite Pool 关闭。

### 2.5 结构化错误和日志

- 用户错误 DTO 包含稳定 `code`、`message_key`、参数和 UUID v7 `trace_id`。
- 适配器原始错误只进入本机 tracing 日志。
- 日志使用无 ANSI 的每日滚动文件和非阻塞写入。
- 日志级别遵守 `RUST_LOG`；测试环境当前为 `warn`，门禁使用 WARN 事件验证落盘。
