# 紧凑配置界面验收

> 日期：2026-10-04。
> 交付记录更新：2026-10-07。
> 状态：紧凑布局、表单对齐、环境选择和操作名称调整已通过本机验证及 Windows 构建。实机测试仍暂停。

实施人员在“智能屏操作 → 修改小新配置 → 配置修改”中，可在固定表单修改所选屏的常用配置，在下方列表检查每台屏的读取结果和不同配置。大量屏只滚动列表数据，表单、表头、分页和提交操作保持可见。

## 1 当前界面

- 表单为两列三行：选择环境、OTA 地址、WebSocket(可选)、H5地址(可选)、H5检测和重新读取配置。字段名称与小新设置页保持一致，去掉“重新选屏”按钮。
- 标签下方不显示当前值、未读取或修改状态说明行，避免不同项高度不一致；未读取提示放在输入控件内。H5 检测的勾选文案为“检查H5地址”。
- 地址直接显示读取值；输入修改后显示橙色边框，可撤销。删空可选地址表示清空手动值，OTA 地址不能清空。
- 不另设环境切换勾选。用户选择其他环境时，本次修改包含运行环境切换；首次读取自动显示的环境不算用户修改，改回所有已选屏当前环境后取消切换。
- 操作选择和屏详情统一显示“修改小新配置”，位于“注册/更新到平台”之后。
- 默认保留每台原值。多数屏值相同时展示该值，其他屏标出差异；最高数量并列时不任取一台。只增加首尾空白不会触发对少数屏的覆盖。
- 列表显示屏名称、IP、检查时间、检查状态和配置差异。悬停差异可看不同项，点击差异或详情可看该屏实际配置、地址来源、拟修改内容和重启要求；设备名在详情中逐台编辑。
- 读取失败不允许提交。重新读取保留编辑内容及已取消的选择；恢复草稿仍须重新读取。翻页不丢失其他页的选择，检查与提交按所有已选屏的实际变化计算。
- 列表使用 4px 细滚动条，移出后隐藏滑块并保留位置；表头与数据列共用列宽。
