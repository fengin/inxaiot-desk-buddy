# 系统与硬件时钟同步校准验收

日期：2026-10-09。适用范围：实施人员使用工作台“校准时间”操作维护已验证的 4 寸与 10 寸智能屏。应用版本：0.2.7。本功能先以 0.2.6 本地验证包完成实机回归及人工验证。

## 1. 实现结果

“校准时间”同时设置屏的系统时间和启动时使用的硬件时钟，避免只修改系统时间、软重启后又被旧硬件日期覆盖。

- 每台实际执行时取当前电脑时间，保留设备原时区、自动校时和自动时区设置。
- 执行前确认固件、管理员权限、唯一的受支持硬件时钟、设备节点、读取与写入命令能力。不具备条件时在修改前停止。
- 系统和硬件时间分别回读，与读取时的电脑时间比较，偏差都不超过 15 秒才显示成功。
- 硬件写入应答或读取不确定时保留待核实。核实仅读取实际状态，不重复写入；系统已正确但硬件仍旧时明确显示未完成。
- 旧任务没有硬件校时记录，不能作为新规则下的完整成功；提示重新执行校准。
- 原任务、日志、设备身份核对、多人操作占用和结果保存方式继续使用。两次写入之间重新检查操作占用。

没有新增 NTP 配置、服务器服务、平台字段或数据库迁移，没有修改小新应用和一体机业务。

## 4. 技术位置

代码运行在工作台所在电脑，通过 ADB 调用 Android 屏端命令。

| 文件 | 职责 |
| --- | --- |
| Rust 文件 `src-tauri/src/infrastructure/smart_screen/device_maintenance.rs` | 接入预检、分步保存、硬件设置前的占用复查、最终核实 |
| Rust 文件 `src-tauri/src/infrastructure/smart_screen/device_maintenance/clock.rs` | 固件与时钟匹配、UTC 校时、两项回读、异常判断和单元测试 |
| Rust 测试文件 `src-tauri/tests/smart_screen_maintenance_real.rs` | 显式启用的两台实机正式任务回归，默认不执行设备写入 |
| Vue 组件文件 `src/features/smart-screen/ScreenOperations.vue` | 校时范围、两项偏差标准和 4 寸断电限制说明 |

系统写入使用 `date -u @<当前时间戳>`，硬件写入使用 `hwclock -w -u -f <已确认的设备节点>`。系统按 UTC 日历文本回读，硬件从内核文件 `since_epoch` 读取 UTC 秒数。硬件节点名只允许 `rtc` 加数字，记录中的路径不能成为任意命令片段。

本机结果沿用原任务 JSON，新增保存硬件驱动、节点、修改前时间、写入阶段和两项偏差。没有新增公共任务类型、业务表字段或另一套校时任务。
