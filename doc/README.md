一体机目录中的 02、03 保留一体机重构阶段完整详细基线及原编号。历史记录引用版本号或原章节时，应定位到这两份详细基线；新业务的公共规则从根目录 02、03 开始阅读。

智能屏平台注册更新仅面向项目侧数据库，使用限定新增、资料更新和确认回读，不连接云平台、不新增平台业务接口。已注册资料修改保存为独立本机草稿；注册成功后单条身份、原本机 ID、历史及缓存保留。真实功能及本轮验收已经接入并完成，具体范围、证据和待补项以智能屏开发计划及逐步验收记录为准。

智能屏技术方案明确：工作过程数据保存在本机，已注册屏的操作结果记录保存在项目工作台专用库，业务结果保存在项目平台业务库。开发前先完成公共代码优化和一体机回归；屏端应用配置修改需要小新应用配合，安排在基础运维之后。
