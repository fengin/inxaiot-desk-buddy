## 1. 当前交付

工作台可对单台或多台屏执行 IP 连通、ADB 管理连接、设备信息、小新安装情况及 MAC 检查。正式页面使用公共任务队列，逐台结果与实测保存在本机，公共任务面板显示进度及日志。检查不会改写平台在线状态、应用版本或设备配置。

新的本机表 `local_screen_task_data` 保存检查依据和结果，避免临时制品清理后丢失历史。确认执行只能使用已经保存的检查；地址、身份或尺寸改变后需要重新检查。同一检查不能重复提交，允许明确选择已经通过检查的部分目标。

中断的只读检查可以核实已保存记录，没有可靠结果的目标保持失败，不重新连接设备冒充原检查成功。共享保存失败与设备结果分开，补存使用原操作编号。

## 2. 实机结果

本次使用 Android 管理工具 ADB 35.0.2，位置为开发机已有 `D:/env/AndroidSdk/platform-tools/adb.exe`。程序也支持应用工具目录、Android SDK 环境变量及 PATH 查找；缺失时明确报错。随发布物提供固定工具的验证仍属于步骤 7。

| 连接地址 | `192.168.3.114:5555` | `192.168.3.73:5555` |
| 型号 | `px30_evb` | `Smart touch panel` |
| Android / SDK | 8.1.0 / 27 | 10 / 29 |
| 应用架构 | 支持 `arm64-v8a`、`armeabi-v7a` | 支持 `armeabi-v7a` |
| 有线 MAC 来源 | 固定读取已确认的 `eth0` | 本次只发现一个有效有线接口 `eth0` |
| 小新版本 | 2.0.9 | 2.0.9 |
| 只读检查 | 通过 | 通过 |

MAC 记录只证明本次运行时读到的地址，不能据此宣称跨烧录永久不变。10 寸出现多个有效有线接口时不自动选一个。4 寸旧固件的时间戳读取有已知差异，程序解析 UTC 日期文本，不使用有问题的 `date -u +%s` 结果计算偏差。
