# 0.2.16 发布记录

日期：2026-10-24。状态：修复范围及功能验收已确认，版本纳入 0.2.16；源码提交、GitHub 构建及正式产物核验待本次发布流程完成后记录。

## 1. 使用目标与交付范围

项目实施和运维人员使用 `inxaiot-desk-buddy`（实施工作台程序）批量安装智能屏应用、核实平台结果或部署升级一体机。本版本要求任务持续推进，取消不被日志锁长期阻塞，已成功的设备操作与结果说明一致；安全结束后回收任务内的大文件副本，同时保留追踪、诊断和恢复所需数据。

本版本包含两组调整：

- 智能屏批量任务收尾、取消事件等锁、本机 SQLite 确认事务、恢复成功提示和安全错误日志。
- 运维电脑上的 APK、镜像及内部发布包临时副本清理；默认一体机部署脚本在健康检查成功后清理本次已导入的镜像 tar。

实施人员选择的原始安装包、任务日志、诊断报告、安装元数据、未核实结果、中断一体机任务和必要备份继续保留。已有自定义一体机部署脚本不被内嵌版本覆盖；已结束的旧历史提示不批量改写。生产数据目录未参与测试或清理，没有新增平台表结构或本机数据库迁移。

本机代码运行在运维电脑；已有文件 `src-tauri/resources/agent/edge-node-agent.sh`（一体机部署脚本）由工作台内嵌、上传并在目标一体机执行。本次不修改小新 APP、H5 或平台业务接口。

## 4. 升级与数据保留

实施人员在没有活动任务时正常退出旧工作台，核对新产物版本和SHA-256后更换程序。原项目、凭据、资产、草稿、历史与诊断继续使用原数据目录，不因更换程序重新导入或重建。

启动清理只处理受管、已核实可回收的任务副本；运行中、取消中、结果待核实、中断及引用关系不明确的文件继续保留。文件占用或清理失败只记录提示并留待后续处理，不为节省空间把成功部署改成失败，也不重放设备动作。

远端镜像tar清理仅适用于使用本次默认脚本完成的新部署或升级，不对历史版本目录进行批量扫描，不执行Docker全局镜像清理。回滚和诊断仍按现有操作规则进行，原始安装包应由实施人员继续保管。

本轮发布不启动或迁移 `D:\data\com.inxaiot.desk-buddy`（生产实例数据目录）。实际GitHub运行、产物下载及校验结果在本记录第2节补齐后，才作为正式交付依据。
