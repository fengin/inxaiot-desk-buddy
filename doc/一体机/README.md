# 一体机管理文档索引

本目录面向维护项目一体机的实施、产品和开发人员，说明资产导入、项目发布配置、部署升级、服务检查及对应验证。公共项目、登录、任务和数据边界先阅读[公共产品设计](../02-产品设计文档.md)与[公共技术方案](../03-技术方案设计.md)。

当前设计基线为应用 **v0.2.8**，更新日期 **2026-10-10**。产品、技术文档正文说明当前规则；历史版本记录、阶段报告和实机验收保留对应日期与验证范围。
