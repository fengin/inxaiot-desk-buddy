# 0.2.20 Windows交付记录

交付日期：2026-11-05。0.2.20 Windows x64优化Release免安装程序及便携压缩包已生成，版本、架构、文件集合、SHA-256和隔离工具自检通过。本次为本地交付，供实施人员试用；源码未提交或推送，未创建标签或发布GitHub版本。

## 1. 实施人员使用

等待旧程序任务完成并正常退出，解压便携包，运行其中的`INX实施工作台.exe`（Windows程序文件）。继续使用原数据目录，项目、设备及历史无需重新导入；不要覆盖仍在运行的程序。适用Windows 10/11 x64，电脑需要已有Microsoft Edge WebView2运行时，ADB工具已内嵌。

主要新增范围：

- “设置智能屏”合并保持ADB端口、NTP、校准时间和关闭屏睡眠，允许4寸、10寸混选。默认选择端口、时间和睡眠，NTP勾选后才修改，空地址表示清除自定义地址。
- 首屏设置并发并读取，完成后选择设置内容；已满足跳过，ADB与NTP按需共享一次系统重启，随后处理时间及睡眠，逐项回读。
- “检查设备”统一完整检查与仅网络检查；默认完整，勾选仅网络可快速检查。网络、管理连接、系统/小新信息和检查结果分开展示，平台状态和版本更新仍单独确认。
- 小新配置、系统设置与设备检查的首屏布局、并发和底部按钮统一，输入及结果摘要保持紧凑。

一体机部署沿用原时钟核对和非root SSH账号的`sudo -n`（Linux免交互提权命令）行为。该行为与智能屏已有ADB权限分开，不新增Windows管理员权限要求。
