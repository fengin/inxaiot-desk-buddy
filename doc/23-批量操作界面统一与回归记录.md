# 批量操作界面统一与回归记录

> 日期：2026-10-08。
> 状态：界面统一、完整前端回归、源码类型检查和 Windows 普通构建通过。
> 范围：Windows 工作台的智能屏批量操作、一体机部署升级及相关确认与历史页面。

实施人员处理多台设备时，参数、检查摘要和操作按钮固定显示，设备列表占用剩余空间并单独滚动。界面采用紧凑表格，减少重复卡片和说明，不改变实际执行范围、业务确认或保存内容。统一规则见[界面规范第 14.5 节](01-桌面工作台界面设计规范.md#145-智能屏与一体机批量操作页面)。

## 1 已统一的页面

| 业务范围 | 当前展示与保留的交互 |
| --- | --- |
| 智能屏选屏与安装参数 | 名称、IP、位置等同类信息对齐；小窗口筛选与选择统计固定分行。参数与执行按钮固定，批量设备资料单独滚动 |
| 安装、校时、端口保持和重启检查 | 逐屏检查采用表格；只读检查等其他动作沿用相同选屏、检查和结果组件。校时偏差显示在行内，完整时间、时区与开关信息可打开详情 |
| 注册更新 | 左侧逐屏列表固定表头；右侧保留资料差异、MAC 沿用和空间变更确认。矮窗口按需打开完整字段对比，必要确认留在当前页 |
| 关键资料待修改 | 阻断提示及处理操作固定，完整地址与待修改资料在明确的“查看修改”弹窗中展示；不改变原阻断条件 |
| 平台状态覆盖、版本同步 | 预览与结果统一为紧凑表格；名称、IP、检查时间、状态或版本分别成列；选择统计、分页和确认按钮固定，翻页不改变完整提交范围 |
| 导入与疑似重复合并 | 导入预览固定批量修正工具和提交区，设备行独立滚动；错误行仍阻止提交。合并候选改表格，保留逐字段选源和身份确认，字段较长时对比区可单独滚动 |
| 智能屏操作结果与共享历史 | 结果继续使用每屏一行的表格；共享记录的摘要与释放操作固定，逐台详情、前后值和长说明可查看。释放占用仍需二次确认，长占用清单在弹窗内单独滚动 |
| 一体机首次部署、整包升级、单服升级 | 三种模式共用的选择、预检、执行和结果页面统一固定区域和表格。设备预检失败明细及处理按钮保留；执行取消、参数重试、结果核实按原规则处理 |
| 一体机共享历史与详情 | 统计改为紧凑摘要，历史记录和逐台结果采用固定表头表格，详情往返与底部关闭操作保持可用 |

执行快照未提供历史 IP 时，不把当前资料冒充历史实测。一体机执行和结果中新展示的 IP 明确标为“IP（当前资料）”；已有历史 MAC 保留。

长发布参数、完整诊断和单台设备详情不属于重复设备卡片。其必要的内部滚动与业务说明保留，不通过裁切信息凑成一屏。

## 2 代码位置与边界

源码工程为 `inxvision-assistance/inxaiot-desk-buddy`，界面运行在实施人员的 Windows 电脑。

下表中的智能屏目录指 `src/features/smart-screen/`。

| 已有或新增文件 | 职责 |
| --- | --- |
| 新增 Vue 组件 `src/shared/components/CompactOperationTable.vue` | 固定表头、共用列宽、紧凑单元格和设备数据滚动；不包含业务接口 |
| 智能屏目录的 `ScreenPreflightTable.vue`、`ScreenOperations.vue`、`ScreenRegistrationPreview.vue`、`ScreenTimeCheck.vue`、`ScreenInstallFields.vue`、`screen.css`、`registration.css` | 各检查步骤、注册确认、参数及按需详情 |
